# 🛒 Blinkit Grocery Sales Analysis using Microsoft Excel

## 📌 Project Overview

This project focuses on analysing Blinkit grocery sales data using Microsoft Excel to identify sales trends, evaluate product performance, compare outlet performance, and generate meaningful business insights.

The main objective is to transform raw retail sales data into structured information that helps understand customer purchasing patterns, product visibility, and outlet-level sales performance.

## 🎯 Project Objectives

- Analyse overall grocery sales performance.
- Identify the highest- and lowest-performing product categories.
- Compare sales across different outlet types and sizes.
- Examine the impact of product fat content on sales.
- Analyse the relationship between product visibility and sales.
- Perform statistical analysis to understand sales distribution and variation.
- Identify unusual sales values using statistical techniques.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- PivotTables and PivotCharts
- Excel Formulas and Functions
- Data Cleaning and Data Transformation
- Statistical Analysis
- Data Visualization

## 📊 Key Performance Indicators (KPIs)

The project examines the following metrics:

- Average Sales
- Median Sales
- Minimum Sales
- Maximum Sales
- Standard Deviation
- Variance
- Coefficient of Variation
- Average Product Visibility

## 🔍 Analysis Performed

### 1. Sales Performance Analysis
Evaluated overall sales performance using descriptive statistics and key metrics.

### 2. Product Category Analysis
Compared sales across product categories to identify high- and low-performing categories.

### 3. Outlet Performance Analysis
Examined sales contributions across different outlet types and outlet sizes.

### 4. Product Fat Content Analysis
Compared Low Fat and Regular product sales across different outlet types.

### 5. Product Visibility Analysis
Investigated the relationship between product visibility and average sales using grouped visibility ranges.

### 6. Statistical Analysis
Applied statistical methods, including standard deviation, variance, coefficient of variation and the IQR method, to study sales distribution and identify potential outliers.
